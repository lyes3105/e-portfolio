Documentation : Déploiement d'un fond d'écran via GPO pour les utilisateurs de la MFC

Auteur : Lyes Mouhoun | Date : 07/04/2026 | Réalisation professionnelle n°1

Objectif : Déployer un fond d'écran personnalisé MFC à l'ensemble des utilisateurs du domaine mfc.local via une stratégie de groupe (GPO), en respectant la méthodologie AGDLP.

1. Prérequis

Élément Détail
Serveur AD SVLIL-ADMADS1 — Windows Server 2022 — 10.10.20.1
Domaine mfc.local
Client de test Windows 11 — joint au domaine mfc.local
Image du fond d'écran Fichier .jpg ou .png — résolution recommandée : 1920×1080
Partage réseau \\SVLIL-ADMADS1\Partage_MFC\fond_ecran_mfc.jpg

2. Mise en place du partage réseau pour l'image

Étape 2.1 — Créer le dossier partagé

  1. Sur le serveur SVLIL-ADMADS1, créer le dossier : C:\Partage_MFC
  2. Y placer le fichier image du fond d'écran : fond_ecran_mfc.jpg
  3. Clic droit sur le dossier → Propriétés → onglet Partage → Partage avancé
  4. Cocher Partager ce dossier — Nom du partage : Partage_MFC
  5. Cliquer sur Autorisations → Ajouter le groupe Tout le monde en Lecture

Étape 2.2 — Vérifier les permissions NTFS

  1. Onglet Sécurité → Vérifier que Utilisateurs du domaine ont un accès en Lecture
  2. Le chemin UNC final sera : \\SVLIL-ADMADS1\Partage_MFC\fond_ecran_mfc.jpg
⚠️ Important : L'image doit être accessible en lecture par tous les utilisateurs du domaine. Un partage réseau est nécessaire, car un chemin local (C:\...) ne fonctionnera pas sur les postes distants.

3. Méthodologie AGDLP — Gestion des droits

La méthodologie AGDLP (Account → Global Group → Domain Local Group → Permission) est une bonne pratique Microsoft pour structurer les droits d'accès dans un domaine Active Directory.

3.1 — Créer le Groupe Global GG_utilisateurs

Procédure

  1. Ouvrir le Gestionnaire de serveur → Outils → Utilisateurs et ordinateurs Active Directory
  2. Naviguer vers l'OU souhaitée (ex. : mfc.local → Utilisateurs)
  3. Clic droit → Nouveau → Groupe
  4. Nom du groupe : GG_utilisateurs
  5. Étendue du groupe : Globale
  6. Type de groupe : Sécurité
  7. Valider avec OK

3.2 — Ajouter l'utilisateur Pierre Bus dans le groupe global

Procédure

  1. Dans Utilisateurs et ordinateurs Active Directory, localiser l'utilisateur Pierre Bus
  2. Clic droit sur Pierre Bus → Propriétés → onglet Membre de
  3. Cliquer sur Ajouter → saisir GG_utilisateurs → Vérifier les noms → OK
  4. Valider avec Appliquer puis OK

3.3 — Créer le Groupe Domaine Local DL_fond-d'ecran

Procédure

  1. Dans la même OU, clic droit → Nouveau → Groupe
  2. Nom du groupe : DL_fond-d'ecran
  3. Étendue du groupe : Domaine local
  4. Type de groupe : Sécurité
  5. Valider avec OK

3.4 — Imbriquer le Groupe Global dans le Groupe Domaine Local

Procédure

  1. Clic droit sur DL_fond-d'ecran → Propriétés → onglet Membres
  2. Cliquer sur Ajouter → saisir GG_utilisateurs → Vérifier les noms → OK
  3. Le groupe GG_utilisateurs apparaît dans la liste des membres
  4. Valider avec Appliquer puis OK
✅ Résultat AGDLP : L'utilisateur Pierre Bus est membre de GG_utilisateurs, lui-même imbriqué dans DL_fond-d'ecran. Tout utilisateur ajouté au groupe global héritera automatiquement de la GPO.

4. Création de la GPO — Fond d'écran

Étape 4.1 — Ouvrir la console de gestion des stratégies de groupe

  1. Sur SVLIL-ADMADS1, ouvrir le Gestionnaire de serveur
  2. Outils → Gestion des stratégies de groupe (GPMC)
  3. Développer : Forêt : mfc.local → Domaines → mfc.local

Étape 4.2 — Créer la GPO

  1. Clic droit sur Objets de stratégie de groupe → Nouveau
  2. Nom de la GPO : GPO_Fond_Ecran_MFC
  3. Cliquer sur OK

Étape 4.3 — Modifier la GPO

  1. Clic droit sur GPO_Fond_Ecran_MFC → Modifier
  2. Naviguer vers :
    Configuration utilisateur → Stratégies → Modèles d'administration → Bureau → Bureau
  3. Double-cliquer sur Papier peint du Bureau
  4. Cocher Activé
  5. Dans le champ Nom du papier peint, entrer le chemin UNC :
    \\SVLIL-ADMADS1\Partage_MFC\fond_ecran_mfc.jpg
  6. Style du papier peint : Remplir (ou Étirer selon la préférence)
  7. Cliquer sur Appliquer puis OK
⚠️ Note : L'option « Ne pas autoriser les modifications du papier peint » peut également être activée dans le même dossier pour empêcher les utilisateurs de changer le fond d'écran.

5. Liaison et filtrage de la GPO

Étape 5.1 — Lier la GPO à l'OU

  1. Dans la GPMC, clic droit sur l'OU cible (ex. : mfc.local ou une OU spécifique)
  2. Sélectionner Lier un objet de stratégie de groupe existant
  3. Choisir GPO_Fond_Ecran_MFC → OK

Étape 5.2 — Appliquer le filtrage de sécurité

  1. Cliquer sur la GPO GPO_Fond_Ecran_MFC dans la GPMC
  2. Dans l'onglet Étendue, section Filtrage de sécurité
  3. Supprimer Utilisateurs authentifiés (par défaut)
  4. Cliquer sur Ajouter → saisir DL_fond-d'ecran → OK
✅ Résultat : Seuls les membres du groupe DL_fond-d'ecran (donc les membres de GG_utilisateurs, dont Pierre Bus) recevront la GPO du fond d'écran.

6. Vérification et tests

Étape 6.1 — Forcer l'application de la GPO

  1. Sur le poste client Windows 11, ouvrir une invite de commandes en administrateur
  2. Exécuter la commande : gpupdate /force
  3. Attendre le message de confirmation : « La mise à jour de la stratégie s'est terminée avec succès. »
  4. Se déconnecter puis se reconnecter avec le compte Pierre Bus

Étape 6.2 — Vérifier l'application

  1. Après la reconnexion, le fond d'écran MFC doit s'afficher automatiquement sur le bureau
  2. Pour confirmer, exécuter : gpresult /r
  3. Vérifier que GPO_Fond_Ecran_MFC apparaît dans la liste des GPO appliquées
  4. Vérifier que l'utilisateur ne peut pas modifier le fond d'écran (clic droit → Personnaliser → option grisée)
✅ Validation finale : Le fond d'écran MFC est déployé avec succès via GPO pour les utilisateurs du groupe GG_utilisateurs en respectant la méthodologie AGDLP.
