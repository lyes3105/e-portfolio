Projet E-Portfolio — BTS SIO SISR

Lyes Mouhoun — Année scolaire 2024-2026

1. Contexte du projet

Dans le cadre de la formation BTS SIO option SISR au Lycée Turgot (Paris), chaque étudiant doit réaliser un portfolio numérique regroupant l'ensemble de ses compétences, projets et expériences professionnelles. Ce portfolio sert de support pour les épreuves E4 et E6 du BTS SIO et constitue également une vitrine professionnelle.

2. Objectifs

2.1 Objectif principal

Concevoir et développer un site web portfolio moderne, responsive et interactif permettant de présenter de manière professionnelle le parcours de l'étudiant.

2.2 Objectifs secondaires

  • Mettre en valeur les compétences techniques acquises en BTS SIO SISR
  • Centraliser tous les documents officiels (CV, tableau de synthèse, rapports de stage)
  • Présenter les projets réalisés avec leur documentation associée
  • Intégrer une section de veille technologique sur l'IA en cybersécurité
  • Proposer un formulaire de contact fonctionnel
  • Assurer une accessibilité et une lisibilité optimales

5. Spécifications techniques

5.1 Technologies imposées

  • Front-end : HTML5, CSS3, JavaScript (vanilla)
  • Back-end : PHP (formulaire de contact)
  • Versionnage : Git avec dépôt GitHub
  • Hébergement : GitHub Pages (front) + OVH (PHP)

5.2 Contraintes techniques

  • Pas de framework CSS (design 100% personnalisé)
  • Site en une seule page (Single Page Application)
  • Compatible Chrome, Firefox, Edge (dernières versions)
  • Temps de chargement initial < 5 secondes
  • Poids total du site < 100 Mo
